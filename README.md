All computational pipelines and CLI solvers are permanently packaged, versioned, and indexed in official public package managers:

```bash
# 1. Install the Grand Unified Spatial Continuum Framework (Flagship CLI)
conda install -c bioconda spatial-continuum

# 2. Or run via BioContainers Docker (Cloud / Cluster)
docker run --rm quay.io/biocontainers/spatial-continuum:1.0.2--pyhdfd78af_0 cri-calc --help

# 3. Or run via BioContainers Singularity (HPC / Hospital Clusters without root)

# 4. Install the In Situ Evolutionary Game Assay Engine
conda install -c bioconda insitugame
```

## 🩺 Clinical Platforms & Medical Education

### 🩺 [MedTerminal Cardio-Toracico](https://github.com/Lukecele/cardio-thoracic-medterminal)

An interactive multimodal clinical simulation and educational platform developed for medical students at Università degli Studi di Napoli Federico II:
- **3D Interactive WebGL Anatomy:** Anatomical cardiac and thoracic models powered by Three.js.
- **Simulated Real-Time ECG Telemetry:** Dynamic waveform rendering across normal sinus rhythm, conduction blocks, and acute STEMI/NSTEMI patterns.
- **Remastered Clinical Auscultation:** High-fidelity audio syntheses of cardiac murmurs (AS, MR, AR) and respiratory lung sounds.
- **Active Recall Diagnostic Modules:** Case-based clinical reasoning puzzles and bedside medical calculators.
- **Modern Web Stack:** Built with `React 19`, `TypeScript`, `Three.js`, and `Tailwind CSS v4`.  
  👉 **[Explore the live educational platform ↗](https://cardio-thoracic-medterminal.vercel.app)**
